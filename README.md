# Currency Converter Web App 💱

A simple, responsive, and interactive currency converter web application built using HTML, CSS, and JavaScript that allows users to convert currencies in real-time.

## 🚀 Live Demo
👉 [View Live Website](https://shika-currency-converter.netlify.app/)

## ✨ Features
- Real-time exchange rate calculation
- Clean and user-friendly interface
- Responsive design for all devices
- Built with vanilla JavaScript using Fetch API

## 🛠️ Tech Stack
- **HTML5** - For structure
- **CSS3** - For styling and layout
- **JavaScript (ES6)** - For application logic and API integration
